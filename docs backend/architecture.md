# Структура бэкенда

```text
src/backend/
├── app/
│   ├── main.py                  # Точка входа FastAPI
│   ├── core/
│   │   ├── config.py            # Настройки приложения
│   │   ├── security.py          # Пароли и сессии
│   │   └── permissions.py       # Проверка ролей и прав
│   ├── db/
│   │   ├── base.py              # База моделей
│   │   └── session.py           # Подключение к БД
│   ├── modules/
│   │   ├── auth/                # Регистрация, вход и выход
│   │   ├── users/               # Пользователи и профили
│   │   ├── labs/                # Лабораторные работы
│   │   ├── groups/              # Группы и приглашения
│   │   ├── assignments/         # Назначения лабораторных
│   │   ├── submissions/         # Решения студентов
│   │   └── runs/                # Запуски и результаты проверок
│   ├── integrations/
│   │   └── fpga/
│   │       ├── client.py        # Интерфейс связи со стендом
│   │       ├── local.py         # Локальный вызов диспетчера
│   │       ├── ssh.py           # Работа через SSH и SFTP
│   │       └── schemas.py       # Форматы статуса и результата
│   └── worker/
│       ├── main.py             # Фоновая обработка проверок
│       └── queue.py            # Очередь заданий
├── migrations/                 # Миграции БД
├── tests/                      # Тесты бэкенда
├── pyproject.toml              # Зависимости проекта
├── .env.example                # Пример настроек
└── Dockerfile                  # Образ бэкенда
```

Структура внутри каждого модуля из `app/modules/`:

```text
module/
├── router.py                   # HTTP-маршруты
├── schemas.py                  # Форматы запросов и ответов
├── service.py                  # Бизнес-логика
├── repository.py               # Запросы к БД
└── models.py                   # Модели таблиц
```
